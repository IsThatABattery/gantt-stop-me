# Mockups

Design Component pages from the Claude Design canvas. They need that canvas's runtime to render, which is not included. Read them as HTML and CSS reference; do not port the `{{ }}`, `<sc-for>`, `<sc-if>`, or `<dc-import>` template tags.

`canvas.json` is the canvas layout index: which frames exist, their size, their page (Main views, Supporting screens, Objective planner), and some freehand sketch notes. It is not needed to build the app.

All content is placeholder data.
